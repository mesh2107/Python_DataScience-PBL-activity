# Hospital Patient Record Analysis System

A simple college-level Hospital Patient Record Analysis System built using Streamlit.

## Features
- Add patient records
- View all records
- Search patients
- Delete patient records
- Dashboard with KPIs
- Department-wise analysis
- Gender and blood-group charts
- Age distribution
- Treatment-cost analysis
- Export records to CSV
- Local CSV data storage

## Installation

Open terminal in this project folder:

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```

The application will open in your browser.
